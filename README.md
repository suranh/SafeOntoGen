# SafeOntoGen

SafeOntoGen is the framework presented in the manuscript *An Adaptive Ontology–LLM Framework for Simulation-Based Reenactment of Korean Traffic Accidents*.

This repository provides the research materials associated with the manuscript:

- 431 keyword records used for ontology classification;
- the extended catalog of 130 non-Korean elements, consisting of 65 L2 and 65 L3 elements;
- the verbatim system and user prompts used for each module; and
- the behavioral code snippets used as references for scenario generation.

The original Traffic Accident Analysis System (TAAS) records are not included. The traffic accident records used in the study are publicly accessible through TAAS.
